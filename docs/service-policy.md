# 서비스 · 계약/정산 정책 — 부동산이즈 경주역신도시부동산

> 기준일: 2026년 11월
> 중개보수 요율은 「공인중개사법 시행규칙」 제20조와 경상북도 조례 기준입니다. 법령이 바뀌면 변경된 기준을 따릅니다.
> 【제안값】 표시는 운영 기준 초안으로, 대표 확인 후 확정합니다.

---

## 1. 서비스 범위

| 서비스 | 내용 | 비용 |
|---|---|---|
| 매물 상담 | 전화·방문·문자 상담, 시세 안내 | 무료 |
| 매물 안내(방문) | 매물 현장 동행 확인 | 무료 |
| 매물 접수 | 매도·임대 의뢰 접수 및 광고 | 무료 (계약 성사 시 중개보수만 발생) |
| 권리관계 확인 | 등기사항증명서·건축물대장·토지이용계획 확인 및 설명 | 중개보수에 포함 |
| 계약서 작성 | 계약서, 중개대상물 확인·설명서 작성 및 교부 | 중개보수에 포함 |
| 잔금 진행 | 잔금일 일정 조율, 관리비 정산 안내 | 중개보수에 포함 |
| 드론 촬영 | 토지·상가·단지 항공 촬영 (중개 의뢰 매물) | 【제안값】 중개 의뢰 매물은 무료 |
| 공동중개 | 타 중개사무소와 공동중개 | 각 사무소가 자기 의뢰인에게서 보수 수령 |

**하지 않는 업무**
- 세금 신고 대행, 법률 대리, 대출 심사 결정은 하지 않습니다. 필요 시 세무사·법무사·금융기관을 안내합니다.
- 법정 상한을 넘는 중개보수, 법령이 금지하는 사례금은 받지 않습니다.

## 2. 응대 기준 【제안값】

| 항목 | 기준 |
|---|---|
| 전화 부재 시 회신 | 영업시간 내 2시간 이내 |
| 문자·카카오톡·홈페이지 문의 회신 | 영업일 기준 24시간 이내 |
| 매물 방문 예약 | 희망일 1일 전까지 예약 권장 (당일 방문은 매물 사정에 따라 가능) |
| 매물 접수 후 광고 게시 | 확인 완료 후 1영업일 이내 |
| 매물 정보 갱신 | 가격·상태 변경 시 1영업일 이내 수정, 거래 완료 매물은 즉시 내림 |

## 3. 매물 접수 절차 (매도인·임대인)

1. 상담: 희망 가격, 거래 유형, 입주 가능일 확인
2. 현장 확인: 실내 상태, 옵션, 하자 여부 확인 및 사진 촬영
3. 서류 확인: 등기사항증명서로 소유자·근저당 확인
4. 광고 게시: 네이버 매물, 네이버 카페, 홈페이지에 등록
5. 진행 보고: 문의·방문 현황을 의뢰인에게 공유

**접수 시 필요한 것**
- 소유자 성함, 연락처
- 희망 가격(매매가 또는 보증금·월세), 입주 가능일
- 관리비 수준, 옵션 목록
- 실내 사진 촬영을 위한 방문 일정

---

## 4. 계약 절차 (매수인·임차인)

1. 상담 및 조건 정리 (예산, 희망 동·층·면적, 입주일)
2. 매물 방문 확인
3. 가계약금 협의 (선택 사항, 금액과 반환 조건을 문자로 남김)
4. 본계약: 계약서 작성, 중개대상물 확인·설명서 교부, 계약금 지급 (통상 거래금액의 10%)
5. 중도금 (해당 시)
6. 잔금 및 입주: 잔금 지급, 열쇠 인도, 관리비·공과금 정산
7. 신고: 매매 실거래 신고(계약일로부터 30일 이내), 주택 임대차 신고(해당 시 30일 이내)

**계약 당일 준비물**
| 구분 | 준비물 |
|---|---|
| 매수인·임차인 | 신분증, 도장(또는 서명), 계약금 |
| 매도인·임대인 | 신분증, 도장, 통장 사본 (대리인일 경우 위임장·인감증명서) |

## 5. 중개보수 (복비)

### 5-1. 주택 (아파트 포함) 매매·교환

| 거래금액 | 상한요율 | 한도액 |
|---|---|---|
| 5천만원 미만 | 0.6% | 25만원 |
| 5천만원 이상 ~ 2억원 미만 | 0.5% | 80만원 |
| 2억원 이상 ~ 9억원 미만 | 0.4% | 없음 |
| 9억원 이상 ~ 12억원 미만 | 0.5% | 없음 |
| 12억원 이상 ~ 15억원 미만 | 0.6% | 없음 |
| 15억원 이상 | 0.7% | 없음 |

### 5-2. 주택 임대차 (전세·월세)

| 거래금액 | 상한요율 | 한도액 |
|---|---|---|
| 5천만원 미만 | 0.5% | 20만원 |
| 5천만원 이상 ~ 1억원 미만 | 0.4% | 30만원 |
| 1억원 이상 ~ 6억원 미만 | 0.3% | 없음 |
| 6억원 이상 ~ 12억원 미만 | 0.4% | 없음 |
| 12억원 이상 ~ 15억원 미만 | 0.5% | 없음 |
| 15억원 이상 | 0.6% | 없음 |

### 5-3. 주택 외 (상가·토지)
- 매매·임대 모두 거래금액의 0.9% 이내에서 의뢰인과 협의해 결정합니다.

### 5-4. 오피스텔 (전용 85㎡ 이하, 부엌·화장실 등 갖춘 경우)
- 매매 0.5% 이내, 임대차 0.4% 이내

### 5-5. 거래금액 계산 기준
- 월세: 보증금 + (월 차임 × 100). 이 금액이 5천만원 미만이면 보증금 + (월 차임 × 70)으로 다시 계산합니다.
- 분양권: 거래 당시까지 납부한 금액(융자 포함) + 프리미엄
- 주택과 상가가 함께 있는 건물: 주택 면적이 1/2 이상이면 주택 요율, 미만이면 주택 외 요율 적용

### 5-6. 계산 예시 (상한 기준)
| 거래 | 계산 | 중개보수 상한 |
|---|---|---|
| 아파트 매매 3억 1,000만원 | 3억 1,000만원 × 0.4% | 124만원 |
| 아파트 매매 3억 6,000만원 | 3억 6,000만원 × 0.4% | 144만원 |
| 아파트 전세 1억 8,000만원 | 1억 8,000만원 × 0.3% | 54만원 |
| 월세 보증금 1,000만원 / 월 80만원 | 1,000만 + 8,000만 = 9,000만원 × 0.4% = 36만원 → 한도 적용 | 30만원 |
| 월세 보증금 300만원 / 월 40만원 | 300만 + 4,000만 = 4,300만원(5천만 미만) → 300만 + 2,800만 = 3,100만원 × 0.5% | 15만 5천원 |
| 상가 매매 5억원 | 5억원 × 0.9% 이내 협의 | 450만원 이내 |

### 5-7. 지급 원칙
- 중개보수는 매도인·매수인(임대인·임차인) **각자** 지급합니다.
- 금액은 상한요율 이내에서 **계약 전에** 협의해 확정하고 안내합니다.
- 지급 시기: 별도 약정이 없으면 잔금 지급이 끝난 날에 지급합니다.
- 지급 방법: 계좌이체 또는 현금. 현금영수증 발급 가능합니다.
- 부가가치세: 【확인 필요】 사무소 과세유형(일반/간이)에 따라 별도 부과 여부를 안내합니다.
- 중개사의 고의 또는 과실로 계약이 무효·취소·해제된 경우 중개보수를 받지 않습니다.

## 6. 계약 해제·취소 시 정산

| 상황 | 처리 |
|---|---|
| 가계약금 지급 후 본계약 전 취소 | 문자로 남긴 약정 조건에 따릅니다. 조건이 없으면 당사자 간 협의가 필요하며, 분쟁 예방을 위해 가계약 시 반환 조건을 반드시 기록합니다. |
| 본계약 후 매수인(임차인) 사정으로 해제 | 중도금 지급 전이면 계약금을 포기하고 해제할 수 있습니다 (민법 제565조). |
| 본계약 후 매도인(임대인) 사정으로 해제 | 중도금 지급 전이면 받은 계약금의 2배를 돌려주고 해제할 수 있습니다. |
| 당사자 사정으로 해제된 경우 중개보수 | 중개 행위가 완료된 것으로 보아 보수가 발생할 수 있으며, 금액은 사전 협의합니다. |
| 중개사 과실로 해제 | 중개보수를 받지 않습니다. |

## 7. 소비자 보호

- **손해배상 보장**: 「공인중개사법」 제30조에 따라 공제(또는 보증보험)에 가입되어 있습니다. 개인 개업공인중개사 최소 보장금액은 2억원입니다. 공제증서는 사무소에 게시하며 계약 시 사본을 교부합니다.
- **확인·설명서 교부**: 중개대상물 확인·설명서를 작성·서명해 교부하고, 사무소에 법정 기간 보관합니다.
- **개인정보**: 상담 시 받은 이름·연락처는 중개 목적에만 사용하며, 거래 종료 후 법령이 정한 보관 의무 외에는 파기합니다.
- **광고 기준**: 실제 존재하고 거래 가능한 매물만 광고합니다. 거래 완료 매물은 즉시 내립니다.
